# レポートの読み方

レポートはサーバー 1 台につき 1 つです（`report.xlsx` と CSV）。

## シート

| シート | 内容 | CSV |
|---|---|---|
| サマリ | 件数、注意事項、この結果の限界 | |
| CVE の判定 | CVE の一覧の CVE ごとに、影響有無・ソフトウェア・現在の版・修正版。一覧を渡したときだけ | `report_cve.csv` |
| 要更新ソフト | 1 行 = ソフトウェア × 版。**この版以上に更新すれば、そのソフトの脆弱性がすべて直る版**と、脆弱性の件数。**対応はここから** | `report_updates.csv` |
| 前回との差分 | `--previous` のときだけ。「新たに見つかった」「解消」「継続」 | `report_changes.csv` |
| 脆弱性の一覧 | 見つかった脆弱性すべて（1 行 = 脆弱性 × ソフトウェア）。CVE の一覧にあるものに「○」 | `report_vulns.csv` |
| 収集状況 | OS、回収日時、回収ファイル、照合できたか、読めなかったフォルダ、走査範囲の外で動いているプログラム | |

- CSV は BOM 付きの UTF-8 で、Excel でそのまま開けます。
- Excel の 1 シートは先頭 10 万行までです（`config.yaml` の `xlsx_max_rows`）。CSV は常に全件です。

### 列

| シート | 列 |
|---|---|
| CVE の判定 | CVE、影響有無、ソフトウェア、現在のバージョン、修正バージョン、見つかった場所、備考 |
| 要更新ソフト | ソフトウェア、現在のバージョン、この版以上に更新、脆弱性（件）、うち CVE の一覧にあるもの（件）、修正版の無いもの（件）、見つかった場所、CVE（先頭 10 件） |
| 脆弱性の一覧 | CVE など、影響有無、ソフトウェア、現在のバージョン、修正バージョン、CVE の一覧にある、見つかった場所、備考 |
| 前回との差分 | 変化、CVE など、ソフトウェア、前回のバージョン、今回のバージョン、修正バージョン、見つかった場所 |

## 判定

| 値 | 意味 |
|---|---|
| 影響あり | 入っているソフトの版に、その脆弱性がある |
| 影響あり（比較不能） | ソフトはあるが、版を比べられない（安全側で影響ありにした） |
| 影響なし | このサーバーのソフトからは見つからなかった。Windows OS の脆弱性なら、更新済みか Windows ではない |
| 判定不能 | 確かめられない（照合できるソフトが無い、脆弱性の情報が無い種類のソフトがある、回収が途中で止まった、OS の版が分からない） |

「影響あり」は版の一致です。実際に攻撃できるか（設定や使い方）は人が判断します。

Windows OS そのものの脆弱性は、CVE の一覧を渡したときだけ判定します（一覧の CVE を Microsoft の公開データで調べ、OS のビルド番号と比べます）。影響ありなら「要更新ソフト」に「Windows Update で最新にする」と出ます。

## この結果の限界

「影響なし」は**回収できた範囲と、脆弱性の情報にある範囲での結果**です。

- 判定できないもの: 脆弱性の情報（OSV.dev、Amazon Linux の公式情報、Microsoft の公開データ）に無いソフト（**HULFT・DataMagic などの商用ソフト**）、実行ファイルそのもの（カーネル、node・python のバイナリ、Go / Rust 製 exe の内部）、Windows の OS 以外の Microsoft 製品（Office など）、コンテナの中身、Lambda の実行環境。これらは製品の告知で人が確かめます。
- 取りこぼし: 権限不足や走査範囲外のフォルダ、ネットワークドライブ。「収集状況」で確かめます。
- 使わない系統: RHEL の追加製品・EUS、Ubuntu の FIPS / Realtime（[DEFECTS.md](https://github.com/hsgwa/cve_chk/blob/main/docs/DEFECTS.md) の 4 章）。
- Amazon Linux は x86_64 の情報を arm64 にも使います。EMR 独自のパッケージは含みません。

判定できない範囲と代わりの方法は [ROLLOUT.md](https://github.com/hsgwa/cve_chk/blob/main/docs/ROLLOUT.md) の 7 章、他のツールとの比較と実機での確認は [COMPARISON.md](https://github.com/hsgwa/cve_chk/blob/main/docs/COMPARISON.md) にあります。
